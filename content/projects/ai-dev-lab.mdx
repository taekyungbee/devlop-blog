## 프로젝트 소개

이 블로그 자체가 하나의 풀스택 프로젝트입니다. 단순한 블로그를 넘어 AI 트렌드 자동화 시스템을 갖추고 있습니다.

## 주요 기능

### AI 트렌드 자동 수집
- YouTube 26개 AI 관련 채널 RSS 구독
- Gemini API를 활용한 영상 자동 요약
- 이메일 및 Notion 자동 동기화

### 기술 블로그
- MDX 기반 콘텐츠 관리
- 코드 하이라이팅 및 Callout 컴포넌트
- Giscus 댓글 시스템

### 인프라
- Docker 컨테이너화
- GitHub Actions CI/CD
- Google Cloud Run 배포

## 기술적 도전

### 영상 요약 파이프라인
YouTube 영상의 자막 또는 오디오를 분석하여 핵심 내용을 요약하는 파이프라인을 구축했습니다.

### 대용량 RSS 처리
26개 채널의 RSS를 효율적으로 처리하기 위한 배치 처리 시스템을 구현했습니다.
