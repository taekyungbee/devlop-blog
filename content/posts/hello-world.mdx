### 코드 예시

다음은 TypeScript로 작성한 간단한 예시입니다:

```typescript
interface Post {
  title: string;
  description?: string;
  date: string;
  tags: string[];
}

function formatPost(post: Post): string {
  return `# ${post.title}\n\n${post.description ?? ""}`;
}
```

  이 블로그는 Next.js 15와 MDX를 사용하여 만들었습니다.
